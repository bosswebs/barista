# Beyond Barista Academy - Premium Learning Management System (LMS)

## Project Title

**Beyond Barista Academy - Premium Learning Management System (LMS)**

## Objective

Build a complete premium Learning Management System for **Beyond Barista
Academy Rwanda** (https://www.beyondbarista.rw/) dedicated to
Hospitality Education.

The platform must look as modern and premium as **Coursera**,
**Alison**, **Udemy**, and **Moodle**, while using only free/open-source
libraries and components.

The system must support both FREE and PREMIUM courses.

The website should feel world-class with excellent UI/UX, smooth
animations, responsive layouts, accessibility, and high performance.
